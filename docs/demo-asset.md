# 자동 검사 전용 합성 이미지

`tests/fixtures/synthetic-person.png`는 이 프로젝트를 위해 생성한 가상의 성인입니다. 실제 환자가 아니며 수술 결과 이미지도 아닙니다. 0.7.0부터 사용자 요청으로 예시 기능을 제거해 앱/ZIP에는 포함하지 않습니다. 이전 `public/assets/demo-person.png` 자산을 자동 검사용 폴더로 이동했으며 테스트가 파일을 읽어 가상 카메라에 주입합니다.

생성 도구: OpenAI image generation, 2026-09-09.

요청한 이미지: 정면을 바라보는 약 30세의 가상 동아시아 성인 여성, 중립 표정, 얼굴 전체가 보이는 머리·어깨 구도, 뒤로 정리한 머리, 안경·장신구 없음, 코가 가려지지 않은 자연스러운 피부 질감, 균일한 확산광, 밝은 회색 배경, 남색 상의. 문자·로고·워터마크 없음. 실존 인물 및 전후 결과가 아닌 합성 인물임을 생성 프롬프트에 명시.

일반 자동 검증의 가상 카메라는 이 이미지를 canvas에 그린 뒤 브라우저 `captureStream()`으로 실제 MediaStream을 만듭니다. 이 시험의 MediaPipe 추적 결과는 대체하지 않습니다. 별도의 `tests/profile-filter.mjs`는 알려진3D 좌표와 색상/잡음 패턴으로 GPU 경계를 검사하며 실제 모델 검증과 구분합니다. 검증 중 시스템 웹캠은 열지 않습니다.
