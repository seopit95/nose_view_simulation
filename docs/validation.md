# NoseView 0.1 검증 기록

> 이 문서는 2026-09-09의 과거 검증 기록이다. 현재 작업 폴더의 상태와 이후 검증은 [현재 상태](harness/status.md), 새 검증 방법은 [품질 기준](harness/quality.md)을 따른다.

검증일: 2026-09-09 (한국 시각). 환경: macOS 15.5 / arm64, Node.js 22.12.0, Electron 44.2.0. 대상은 최종 빌드한 NoseView.app이며 개발 서버를 사용하지 않았다.

## 실제 모델과 영상 검사

- Face Landmarker 모델을 앱에 포함한 합성 인물에 실제 실행했다. 임의의 가짜 랜드마크를 사용하지 않았다.
- 0 설정은 원본 영상과 픽셀이 완전히 같았다.
- 코 폭 -80 / 콧대 윤곽 -55 / 코끝 위치 +65에서 960×960 영상 중 20,243픽셀이 변했다. 코 영역 바깥의 변경 픽셀은 0개였다. 이 수치는 해당 예시/설정만 검증한 결과다.
- A/B/C 실제 값 복원, 비교 경계, 일시정지 후 조절, 새 상담 초기화를 확인했다.
- 실제 모델로 가상 영상의 복수 얼굴과 얼굴 없음 상태를 검출해 변형/조절을 껐다.
- 네트워크 오프라인 상태에서 앱을 완전히 다시 불러와 모델 초기화와 추적을 확인했다. 의도적으로 시도한 외부 fetch는 차단되었고 정상 실행 경로의 외부 HTTP 요청은 없었다. 운영체제 전체 트래픽을 캡처한 검증은 아니다.
- 명시적 동의 체크 전 저장 불가, OS 저장 취소, 실제 PNG 쓰기, 올바르지 않은 IPC 이미지 거부를 확인했다. 저장 이미지에는 원본/시뮬레이션 구분과 결과 안내 문구가 있다.

## 카메라 및 오류 처리

합성 사진을 그리는 canvas.captureStream() 가상 영상으로 카메라 프레임 처리를 검증했다. 별도로 Chromium의 **가상 장치**를 사용해 실제 getUserMedia가 Electron 권한 처리기를 통과하는지, 마이크 요청을 거부하는지, 연결 해제 시 실제 미디어 트랙이 ended가 되는지 확인했다. 권한을 자동 허용하는 `--use-fake-ui-for-media-stream` 옵션은 이 검증에 사용하지 않았다. 어떤 검사에서도 시스템의 물리 카메라/마이크를 열지 않았다.

연결 권한 거부, 연결 취소 후 늦게 도착한 스트림 정리, 종료 이벤트에 따른 화면/설정 초기화, mute/unmute 이벤트의 상태 표시와 복구를 검사했다. 입력 전환 전 createImageBitmap 실패가 새 입력을 중단하던 문제와 WebGL 시작 실패가 정상 상태로 덮이던 문제를 독립 코드 리뷰에서 재현했으며, 수정 후 회귀 테스트가 통과했다.

가상 카메라 검증 중 UI에서 `19 fps · 프레임 처리 19 ms`가 한 차례 관측되었다. 시작 직후의 짧은 표본으로, 성능 벤치마크나 센서부터 화면까지의 지연 측정 결과가 아니다. 원래 기획서의 평균 30 fps / 지연 p95 목표 달성 여부는 아직 판정하지 않았다.

## 미검증 및 배포 범위

실물 USB 웹캠, 실제 사람의 얼굴, 의료진 평가, 손/안경/마스크 등 가림, 빠른 움직임, 실제 장치 USB 분리·재접속, 8시간 연속 실행, Windows 및 Intel Mac 실행은 미검증이다. macOS 카메라 사용 사유를 포함했지만 실제 하드웨어의 시스템 권한 대화상자는 확인하지 않았다.

패키지는 개발용이며 Developer ID 서명/Apple 공증/Windows 코드 서명을 하지 않았다. 상용 설치·업데이트·라이선스/환자기록 관리 및 의료적 의도 사용 범위 검토가 남아 있다. 본 시제품은 2D 윤곽 표현이며 수술 결과 예측 또는 물리 계측 정확도를 검증하지 않았다.

## 재현 명령

```sh
npm ci
npm test
npm run make
node scripts/run-packaged-test.mjs
node tests/camera-permission.mjs
npm audit
```

가상 장치 권한 검사는 `npm run make`가 생성한 `out/latest-build.json`을 읽는다. Mac/Windows를 각 운영체제에서 따로 검증한다. 기계 판독용 근거는 `qa/e2e-report.json`, `qa/camera-permission-report.json`이다.
