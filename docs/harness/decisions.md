## D-10. 피부 적용 면적과 효과의 조절 폭 확대

- 상태: 채택, 2026-09-10. 사용자가 현재 피부/촬영 보정의 범위가 너무 작다고 요청했다.
- D-09의 좁은 피부 영역과 약한 톤 범위를 보완한다. 얼굴 안쪽 타원으로 이마·볼·턱에 적용하고 코·눈·눈썹·입술 보호를 유지한다. 밝기/색온도는 ±100과 끝점을 보존하는 gain 곡선, 피부 최대 강도 확대, 화사하게 프리셋을 제공한다.
- 이유: 같은 합성 영상의 지정 피부 샘플 12055개에서 이전 최대 강도의 유의한 픽셀 변화는 1593개(13.2%)였다. 사용자에게 필요한 효과 폭을 얻기 위해 적용 면적과 실제 필터 효과를 함께 바꾼다. 숫자 범위만 넓히지 않는다.
- 기존 모델/추적 해상도/25 GPU 샘플 수를 유지하며 추가 의존성은 없다. 전체 피부의 정밀 분할이나 실물 만족도 보증은 아니다.

## D-11. 촬영 보정과 윤곽 조건 분리, 명시적 기본 설정

- 채택: 2026-09-11 사용자 요청. 전역 톤을 정면 품질 판정과 분리한다. 피부 질감은 현재 프레임의 단일 얼굴 기하만 사용하고 코 변형·저장의 엄격한 판정은 유지한다. 예전 유효 좌표 유지나 전체 화면 흐림으로 얼굴 검출 실패를 숨기지 않는다.
- 대비·채도·색조·그림자·하이라이트와 따뜻하게/맑게를 추가한다. 그림자/하이라이트는 조합 끝값에서도 단조성을 유지하는 다항식, 대비의 비정수 pow 전에는 GPU 반올림 범위를 제한한다.
- 기본 설정 저장 요청으로 D-04의 상담 메모리 원칙에 숫자 설정의 명시적 영속 보관을 추가한다. localStorage 고정 schema만 사용하며 환자 자료·A/B/C는 제외한다. 저장 성공 뒤에만 현재 기본값을 바꾸고 실패/손상을 안내한다.
- 이효리 코 타입은 실제 인물의 측정/복제/수술 결과가 아닌 사용자 명명 프리셋이다. 제시한 약한 시작값은 편집·저장할 수 있고 새 상담 자동 적용은 선택사항이다. “가장 유명한 코” 등 사용자의 전달 내용을 검증된 사실로 제품에 적지 않는다.
- 근거: [상시 보정·설정 작업](tasks/2026-09-11-preferences.md). 새 의존성/원격 서비스 없음.

- 채택: 2026-09-14 사용자 승인. 기존3개 설정과 현재 프레임의 깊이 좌표로 측면 방향2D 변형을 우선 구현하고 실물 피드백을 받는다. D-12의 yaw35°/yaw 감쇠를 대체한다. 콧볼 가로 폭 효과는 측면으로 갈수록 축소하고 콧대·코끝을 방향에 맞게 움직인다. 개인별3D 모델/가려진 표면 복원은 미구현이다.

## D-16. 사진6영역의 독립 조절과8개 공통 설정

- 채택: 2026-09-15 사용자 승인. 사진6영역에 기존 코끝 위치·측면 콧대 라인을 더해8개 조절을 제공한다. 절골 영역은 콧대 폭, 콧망울은 코끝 크기, 비공 내리기는 윗테두리를 내려 노출을 줄이는 의미다. 실제 수술 조작이나 mm 수치로 설명하지 않는다.
- 기존 MediaPipe의 현재 좌표를 사용한 국소 UV 변형으로 구현한다. 정밀 콧구멍 분할·개인별3D 복원은 추가하지 않는다. 보이는 쪽의 최소간격을 검사하고 숨은 쪽은 연속 감쇠한다. 입술 위 감쇠는 혼합 최대값에도 경계가 접히지 않도록 넓게 적용한다.
- 표시명/그룹/방향/숫자는 adjustments.ts 한 곳이 소유한다.8값을 UI·설정·필터·A/B/C·PNG에 사용한다. 저장 schema3은 v1/v2 기존 수치를 보존하고 projection=-bridge, 새 세부4값0으로 이전한다. 명시적 저장 전 기존 파일을 바꾸지 않는다.
- 근거: [부위별 조절 작업](tasks/2026-09-15-region-controls.md). 리뷰의 중간각도 끊김·붕괴 좌표·짧은 입술 간격 결함은 실패 회귀로 고정하고 CPU/GPU를 함께 수정한다. 실제 웹캠의 경계 위치와 자연스러움은 사용자 피드백으로 보완한다.
