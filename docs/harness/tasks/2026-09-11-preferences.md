## 목표·설계

현재 Pipeline은 품질 실패 시 landmarks를 버리고 shader는 uEnabled=0이면 톤도 건너뛴다. 화면 톤과 코 변형의 허용 조건을 분리한다. 단일 얼굴의 현재 좌표만 피부 마스크에 전달하고, 자세/크기 조건을 만족하지 않아도 검증 가능한 얼굴 기하에는 질감 보정을 적용한다. 좌표가 없거나 여러 얼굴이면 전역 톤만 유지한다. 코 조절/PNG는 기존 evaluateFace 조건을 유지한다. INV-01~10 중 06/10을 새 요청에 맞게 수정한다.

촬영 조절은 피부 강도, 밝기, 색온도에 대비·채도·색조·그림자·하이라이트를 추가한다. 전역 색 보정은 양쪽/PNG에 동일하게 적용한다. 검정/흰색 보존, off 동등성, 코/눈/입 질감 보호를 유지한다. 자연스럽게 기본은 부드러운 하이라이트/그림자 조절을 추가한다. 새 의존성·AI 얼굴 생성·캠 드라이버 설정은 도입하지 않는다.

기본 설정은 고정 키의 버전 있는 JSON 한 개에 허용된 숫자와 자동 적용 boolean만 localStorage로 명시적 저장한다. 상담 중 슬라이더 변경은 자동 저장하지 않는다. 손상/미지원 버전/읽기 실패는 공장 기본으로 복구하고 알린다. 쓰기 실패는 저장 성공으로 표시하지 않는다. 영상·랜드마크·A/B/C·환자 정보·장치 ID는 넣지 않는다. 앱 시작/새 상담/입력 변경 시 저장한 기본값을 적용하고 임시 자료는 비운다.

이효리 코 타입은 사용자 명명 프리셋이다. 실제 인물의 측정/재현이라고 표시하지 않는다. 선택 질문에는 답이 없어 사전에 안내한 약한 시작값(폭-18/콧대-10/코끝8)을 편집 가능한 시작점으로 제공했다. 프리셋은 -100~100 범위에서 편집 가능하다. 기본 설정 창에서 현재 코 수치 가져오기/편집과 새 상담 자동 적용을 제공한다. 기존 2D 시제품의 기능 범위를 확대 주장하지 않는다.
