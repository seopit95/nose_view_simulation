## 고정 계약과 설계

- 원본 촬영은 한 번만 한다. 긴 변 최대 1920의 bitmap을 Worker에 전달하고, Worker 내부 960 이내 OffscreenCanvas로 추론한 뒤 같은 bitmap을 반환한다. 작은 영상은 확대하지 않는다. 큐/timeout/stale/close 계약은 그대로다.
- 품질 최소 눈 간격 65px는 추론 해상도 기준을 유지한다. 반환된 정규화 좌표는 표시 bitmap 크기로 해석한다.
- 추적에는 필터 없는 입력만 사용한다. 유효 단일 정면 얼굴에서만 화면 보정을 켠다. 조건 불량이면 원본 영상과 안내를 유지한다.
- 기존 얼굴 좌표로 볼·이마의 부드러운 영역을 정한다. 눈·눈썹·입술 경계점을 포함하는 보호 타원과 코 변형 타원을 명시적으로 제외한다. 피부/머리카락을 정밀 분할한 AI 모델이라고 주장하지 않는다.
- GPU bilateral 방식으로 경계를 보존하며 질감을 완화한다. 중간톤 밝기/색온도는 동일한 필터로 원본·가상에 적용한다. 얼굴 형태를 추가 변형하지 않는다.
- 기본값 자연스럽게: 피부 강도 30/100, 밝기 +12(-30~30), 색온도 0(-50~50). 소프트: 55/+22/+3. 보정 없음: 전부 0. 강도/밝기/색온도를 각각 조절하며 입력 전환·새 상담에서 자연스럽게로 초기화한다.
- 보정 적용 표시와 PNG 내 보정값을 포함한다. 보정 없음은 실제 비보정 영상이다. PNG 동의/로컬 전용 정책은 유지한다.
- 실제 웹캠·다양한 피부/조명·장시간 성능을 가상 시험 성공으로 표시하지 않는다. K-09 모델 상태 문제/서명/배포 시스템/새 백엔드는 범위 밖이다.
