## 목표와 설계

추적된 단일 얼굴을 좌우로 돌릴 때 각도만으로 코 보정을0으로 만들지 않고 측면 방향으로 코 라인을 표현한다. 앱은 빈 카메라 연결 대기로 시작한다. Electron/React/MediaPipe/Three.js를 유지한다. 첫 전달은 현재 프레임의 3D 랜드마크를 이용한 방향 인식 2D 변형이며 개인별 3D 모델 복원이나 수술 결과 예측으로 설명하지 않는다. 실제90° 추적 성공은 사용자 웹캠 검증 항목이다.

필터의 코 축/크기는 양쪽 눈의 화면상 간격 대신 코 세로축·얼굴 높이와 깊이를 포함한 코 폭으로 계산한다. 좌우 회전은90°까지 허용하고 yaw 때문에 강도를 줄이지 않는다. 정면과 측면 변형을 연속적으로 섞고 코끝의 현재 위치 및 회전 방향에 맞춰 윤곽을 움직인다. 기존 설정3개는 그대로 보존한다. 콧대 음수는 정면에서 좁아지고 측면에서는 바깥 라인으로, 코끝 양수는 위/바깥 방향으로 움직인다. 콧볼 폭은 가로 방향 효과이므로 측면으로 갈수록 축소하고65°부터0이다. 별도 측면 높이/돌출 수치는 이번 전달 뒤 사용자 피드백으로 결정한다.

얼굴 없음/복수/잘림/비정상 좌표는 계속 차단한다. 이전 얼굴 좌표를 새 영상에 붙여 고정하지 않는다(INV-01/04). 촬영 전역 톤·상담20°/PNG동의·설정 저장·필터 숫자 고정 계약은 유지한다. 측면에서 사라지는 실제 배경/가려진 표면을 복원한다고 주장하지 않는다.
