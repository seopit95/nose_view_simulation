## 목표와 범위

기본 설정에서 코 타입을 추가하고 이름·코 폭·콧대 윤곽·코끝 위치를 편집해 저장한다. 상담 화면의 셀렉트 박스로 즉시 적용하며, 다음 상담의 기본 타입과 자동 적용 여부를 별도로 지정한다. 기존 Electron/React/localStorage만 사용한다. 삭제·정렬·공유·환자별 저장·모델/렌더링 변경은 포함하지 않는다.

## 계약

- 저장 키 `noseview.preferences.v1`은 유지하고 JSON schema는 버전2로 올린다. 버전1의 코 수치·촬영8개·자동 적용 여부를 단일 ‘이효리 코 타입’으로 읽는다. 읽기만으로 원본 저장값을 덮어쓰지 않는다.
- `nosePresets: {id,name,adjustments}[]`, `defaultNoseId`, `beauty`, `autoNose`만 저장한다. 최대50개, 이름32자(JS UTF-16 길이), ID64자 영숫자/밑줄/하이픈, JSON32768자. 빈 이름/정규화 후 중복 이름/중복 ID/없는 기본 ID는 거부한다. 이름은 React 텍스트로만 표시한다.
- 새 타입은 현재 상담 조절값으로 시작한다. 편집 대상과 다음 상담 기본 대상은 독립적이다. 취소/Escape/저장 실패는 기존 목록·현재 상담·디스크 값을 바꾸지 않는다.
- 선택 시 정면 조건을 만족하면 즉시 적용한다. 같은 타입 다시 적용 버튼도 제공한다. 수동 조절/저장은 현재 선택을 유지한다. 새 상담은 저장 기본 타입을 선택하고 자동 적용이 꺼져 있으면 코 수치는0이다.
- 실시간 필터는 선택 ID와 현재 수치를 고정한다. 필터 첫 연결/장치 변경은 고정값을 유지하고 해제/새 상담은 기존 초기화 계약을 따른다. 피부·카메라 기본값은 공통이다.
