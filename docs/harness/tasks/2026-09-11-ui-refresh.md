## 범위와 설계

기존 화면 흐름의 시각적 개선이다. 사용자 요청을 화면 변경의 승인으로 적용하며 추가 확인 단계 없이 진행한다. 밝은 쿨그레이 배경, 흰 카드, 선명한 블루와 옅은 블루/라벤더 보조색, 둥근 모서리, 읽기 쉬운 글자/여백을 일관되게 적용한다. 상단 탭/연결/촬영 보정/코 조절/프리셋/A·B·C/실시간 필터/설정·저장·새 상담 다이얼로그를 포함한다.

- 기존 CSS를 역할별 토큰과 읽기 쉬운 규칙으로 정리한다. 누적 override나 새 UI 의존성은 추가하지 않는다.
- 버튼/탭의 색·그림자·눌림, dialog/toast 진입에 짧은 CSS 전환을 사용한다. 영상 캔버스/얼굴 픽셀에는 효과·이동 애니메이션을 적용하지 않는다. OS의 모션 줄이기를 따른다.
- 본문/보조 글자 대비와 키보드 focus, 활성/비활성 상태를 구분한다. 체크박스·슬라이더·버튼의 의미와 텍스트 식별을 유지한다.
- 기본 창/최소1100×810에서 영상 비율 유지, 주요 연결·내보내기 버튼 노출, 측면 패널과 설정의 스크롤/포커스, 저장 동의/취소·오류 안내를 확인한다.
- 카메라·추적·보정 알고리즘·설정 schema·저장 계약은 변경하지 않는다. 신규 로고/이미지/폰트 다운로드 없음. 버전0.5.0.
- 시각 방향 참고: [토스 컬러 시스템](https://toss.tech/article/43385), [TDS 구성 요소 안내](https://developers-apps-in-toss.toss.im/design/components.html). 색상 토큰으로 일관성을 관리하는 접근을 참고하며 NoseView 기존 컴포넌트를 직접 스타일링한다.
