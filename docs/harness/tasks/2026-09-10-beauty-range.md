## 목표와 고정 설계

같은 영상에서 보정 강도를 올렸을 때 밝기·색감·피부 질감의 변화가 충분히 커지고 얼굴의 더 넓은 피부에 적용된다. 기존 Electron/MediaPipe/Three.js와 로컬 처리, 동일 프레임/양쪽 동일 보정/저장 동의 계약을 유지한다.

- UI 밝기/색온도 범위 -100~100, 피부 강도는 0~100. 단순 숫자 확대뿐 아니라 GPU 최대 효과를 확대한다.
- 피부 마스크는 좁은 볼/이마 타원 3개에서 얼굴 외곽 안쪽의 단일 타원으로 바꾼다. 같은 프레임의 이마10/턱152/좌우234·454와 눈 축을 사용한다. 기존 눈·눈썹·입술/코 보호 영역은 유지한다. 머리카락/손의 정밀 분할은 아니다.
- 피부 강도에 따라 샘플 간격/색 차이 허용/혼합량을 높인다. 5×5 샘플 수는 고정하며 유효 얼굴·피부 영역에서만 적용한다.
- 밝기는 양 끝점을 보존하는 `gain*color/(1+(gain-1)*color)`, gain=`exp2(brightness/100*2.5)`로 적용한다. 색온도는 같은 곡선에 적/청 gain=`exp2(warmth/100*±0.75)`를 사용한다. 0 설정은 정확히 원본 경로로 반환한다.
- 기본 자연스럽게(30/+12/0), 소프트(55/+22/+3)는 선택값을 유지한다. 화사하게(85/+45/+5)를 추가한다. 보정 없음은 0/0/0. 프리셋은 2×2 배치한다.
- 얼굴 형태 변경/센서 해상도 확대/새 모델/카메라 권한 변경/실물 촬영·저장/실행 중 사용자 앱 종료는 이번 범위 밖이다.

## 실행 순서

1. `tests/beauty.test.ts`: 확대 범위가 clamp로 잘리지 않는지와 누락/역전된 얼굴 외곽 거부를 확인한다. 기존 회전/크기별 보호 시험 유지.
   ```ts
   expect(sanitizeBeauty({ smoothing: 500, brightness: -150, warmth: 150 }))
     .toEqual({ smoothing: 100, brightness: -100, warmth: 100 });
   ```
2. `tests/beauty.mjs`: 동일한 합성 잡음 영상에서 얼굴 피부 샘플 중 30% 이상에 보정이 적용되는지 검사한다. 기존 좁은 마스크를 검출하는 실패를 먼저 확인한다. 최대 강도는 중간 강도보다 같은 피부 영역의 인접 잡음 차이를 줄여야 한다. 밝기 100/-100이 30/-30보다 효과가 크고 색온도 ±100도 ±50보다 변화가 커야 한다. 배경/보호 픽셀·off·거울·0변형·PNG 동등성은 유지한다.
3. `src/core/beauty.ts`: 확대 clamp/새 프리셋/얼굴 타원과 입력 검증. `Viewport.tsx`: 단일 피부 타원과 확대 필터. `App.tsx`, `styles.css`: 슬라이더 범위/프리셋 배치. 기존 입력 상태와 저장 시 동일 설정 사용.
4. 관련 unit → build → 실제 Electron 보정 검사 → 읽기 전용 리뷰 → `npm run verify`. 모델 결과를 대체하지 않고 합성 영상만 사용한다. 창 크기/새 프리셋/양쪽 PNG를 시각 검수한다.
5. 버전 0.2.1로 새 Mac arm64 앱/ZIP을 전달하고 CRC/내부 앱 해시·버전을 확인한다. README/제품/설계/품질/결정/현황에 실제 계약과 검증 한계를 반영한다.

## 관찰과 검증 기록

기존 코드는 피부를 작은 타원 3개에 한정하고 이마/볼 밖에는 강도를 올려도 smoothing이 적용되지 않는다. 밝기 최대는 선형 midtone 계수 0.4, 색온도 최대는 적/청 계수 ±0.06이라 변화 폭이 제한된다.

직전 대화의 실물 점검에서는 HCAM01L, 1280×720, 순간 29fps의 수신 화면을 확인했으나 얼굴이 잘려 추적 대기 상태였다. 카메라 수신 확인을 모든 실물 기능/화질 검증 통과로 확대하지 않는다. 이번 구현 검수는 합성 영상으로 수행한다.

- RED: beauty unit 3실패/1통과(확대 clamp 및 잘못된 턱 경계). 실제 GPU 검사에서 12055개 피부 샘플 중 1593개(13.214%) 변화로 면적 조건 30%에 실패했다. 원본 보고서/합성 화면은 `qa/beauty-range-2026-09-10/baseline-coverage.json/png`에 보존.
- GREEN: 관련 unit 4통과, build 및 실제 Electron beauty 검사 4그룹 통과. 같은 샘플에서 5617개(46.595%) 변화, 강도40→100의 인접 차이 합 215221→169816. 보호600픽셀 및 배경 열 변화0, 코 보호, off/거울/PNG 동일성, 밝기·색온도 확장 끝값의 추가 변화 통과.
- 구현: 얼굴 안쪽 단일 타원, 강도에 따른 smoothing 확대, RGB gain 곡선, 네 번째 프리셋 화사하게, 2×2 프리셋 배치. `core/beauty`, `Viewport`, `App`, `styles`, beauty 시험 2개, package/lock 0.2.1과 소유 문서 변경. 새로운 추론/카메라 데이터 경로는 없다.
- 개발 앱 시각 확인: 화사하게의 넓은 피부 효과/밝은 톤, 양쪽 저장 안내와 보정값, 최소 창 스크롤의 조절값 확인. 합성 영상의 잡음은 의도적인 시험 입력이다.
